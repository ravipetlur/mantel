- **Updates inside the app.** Mantel checks for a new version once a day, or when you choose Check for Updates… in the dot's menu, shows what's new, and installs it when you say so. Every download is checked before it replaces the app: its checksum, Apple's notarization, and that it's signed by the same developer as the copy you're running. This is the last version you install by hand.
- You can turn the daily check off in Settings › About.
