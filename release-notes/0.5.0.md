- **The mic and camera dots stay in the bar.** While an app uses your mic or camera, Mantel hides icons with System Settings' own switches instead, so macOS's orange and green dots stay visible. About 10 seconds after the call ends, it goes back to the usual way. It's on by default; you can turn it off in Settings › Advanced. It needs the same access to the System Settings file as the "System Settings switches" hiding method.
- Mantel never asks for your mic or camera: it only asks macOS whether an app is using them. Its log names that app.
